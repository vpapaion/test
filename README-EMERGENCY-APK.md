# Elderly SOS — Android APK

Αυτός ο κλάδος δημιουργεί αυτόματα εγκαταστάσιμο Android APK για την εφαρμογή **Κλήση Βοήθειας**.

Μετά την πρώτη άδεια τηλεφωνικών κλήσεων, το μεγάλο κόκκινο κουμπί καλεί απευθείας το **6936822967**.

Το GitHub Actions workflow παράγει το artifact **ElderlySOS-v1.0**, το οποίο περιέχει:

- `ElderlySOS-v1.0.apk`
- `ElderlySOS-v1.0.apk.sha256`

Πριν χρησιμοποιηθεί σε πραγματική ανάγκη, πρέπει να γίνει δοκιμαστική εγκατάσταση και κλήση. Η εφαρμογή δεν αντικαθιστά το 112 ή πιστοποιημένη υπηρεσία τηλεβοήθειας.
